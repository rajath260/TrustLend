# Contributing to TrustLend

Thank you for contributing.

## Development principles

- Keep the MVP scope focused.
- Prefer domain correctness over premature microservices.
- Keep money calculations precise.
- Preserve immutable financial history.
- Add tests for lifecycle and settlement edge cases.
- Keep provider-specific integrations behind adapters.
- Never commit secrets or real personal/financial data.

## Pull requests

Explain:
- What changed
- Why it changed
- Tests added/run
- Any database migration
- Any API contract change
